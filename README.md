# Beautiful Soup Web Scraping Project

## Description

This project demonstrates web scraping using Python and Beautiful Soup.

The program extracts book titles and prices from a sample website.

## Website Scraped

https://books.toscrape.com/

## Technologies Used

- Python
- Beautiful Soup
- Requests

## How To Run

Install required libraries:

pip install -r requirements.txt

Run the program:

python scrape.py
